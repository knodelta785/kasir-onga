Berhenti Berlangganan

Menghapus akun dan semua data toko (produk, transaksi, laporan) secara permanen dari Kasir Onga. Emailmu bebas dipakai daftar lagi. Unduh laporan Excel dulu bila masih diperlukan — yang sudah dihapus tidak bisa kembali.

Database: bila Firebase terhubung (indikator "Real-time aktif" di atas), data tersinkron real-time antar semua perangkat (web & APK) dan tersimpan di proyek Firebase milikmu; perubahan offline akan terkirim saat online lagi. Bila indikator "Mode lokal", data hanya tersimpan di perangkat ini. Cetak struk memakai sistem cetak perangkat. Untuk printer Bluetooth, hubungkan printer ke HP dan pilih saat dialog cetak muncul.

Reset Data
